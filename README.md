AI Architect

A \textbf{GenAI system} using \textbf{Hugging Face pipelines} to create \textbf{optimized apartment floor plans} based on user-defined inputs like dimensions, room counts and amenities. Crafted a \textbf{custom Hugging Face dataset of 10,000+ parqueted architectural floor plan images} and \textbf{fine-tuned a distilled transformer} using \textbf{CUDA on an NVIDIA T4 GPU} for conditional image generation, enabling architects to generate \textbf{designs aligned with client specifications}
